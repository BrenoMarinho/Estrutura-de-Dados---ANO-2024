# Estrutura-de-Dados-ANO-2024
Repositório contendo as atividades e avaliações aplicadas durante um semestre letivo de 2024. O projeto apresenta fluxos completos de análise e manipulação de dados, utilizando DataFrames (via Pandas) para estruturar, tratar e explorar as informações de forma eficiente.

## 🚀 Notebooks Desenvolvidos (Google Colab)

Abaixo estão os resumos das atividades e avaliações realizadas nos notebooks presentes neste repositório:

* **Avaliacao_A1_Breno_CCP_07jun24.ipynb:** 
  > Este notebook tem foco prático na biblioteca Pandas. Ele aborda a criação e manipulação de estruturas essenciais de dados, incluindo a construção de `Series` e DataFrames a partir de listas e dicionários. O fluxo engloba comandos para exibir elementos, verificar tamanhos, acessar dados por índices e realizar operações iniciais de estruturação.

* **Avaliação_Breno_D2_ED1_UDF.ipynb:** 
  > Atividade avaliativa focada em Estruturas de Dados, especificamente trabalhando com **Listas** em Python. O notebook mescla conceitos teóricos (definições de dados e algoritmos) com exercícios práticos de fixação. Demonstra a manipulação direta de listas através de interações de usuário e utilização de métodos nativos do Python, como `append()`, `insert()`, `pop()`, funções de agregação como `max()` e `min()`, e limpeza com `clear()`.

* **Data Frame - Análise e Manipulação de Dados de F1 (Pandas):**
  > Avaliação prática focada na aplicação de conceitos de análise de dados com a biblioteca **Pandas**. O notebook aborda:
  > * Criação e estruturação de **DataFrames** e **Series** a partir de dados da Fórmula 1 (pilotos, construtores, pontuações e corridas).
  > * Filtragem, ordenação e seleção de subconjuntos de dados utilizando indexação e métodos do Pandas (`.loc`, `.iloc`, consultas condicionais).
  > * Operações de agregação, agrupamentos e tratamento de colunas para extração de estatísticas e métricas do campeonato.
